# 問卦

六爻、奇門遁甲、塔羅的排盤工具。排出盤面後，一鍵複製「資料包＋解讀指令」，貼給 Claude、ChatGPT 等 AI 解讀。

**線上使用：<https://danielfu17.github.io/paipan/>**

## 功能

### 六爻

- 三種起卦方式：親手擲銅錢後錄入、線上搖卦、數字起卦。
- 京房納甲、八宮世應、六親、六神、伏神。
- 標出旬空、月破、日沖、臨月建、臨日辰、月合、日合。
- 動爻變化：回頭生克、化進退神、化空、化月破、伏吟、反吟、化合。

### 奇門遁甲

- 時家奇門、轉盤，中五宮寄坤二宮。
- 定局法可選拆補（預設）或置閏。置閏依明代《奇門遁甲統宗》的規則。
- 九星、八門、八神、天地盤干、暗干，以及空亡、馬星、門迫、擊刑、入墓。
- 可填年命，可選真太陽時。

### 塔羅

- 偉特體系 78 張，原創線條牌面。
- 牌陣：單張、三張（兩種）、二選一、凱爾特十字。
- 線上洗牌抽牌，或用自己的實體牌手動輸入。
- 依問題推薦牌陣，並提醒不好回答的問法。
- 每張牌都有白話含義。

### 共通

- 點任何一爻、一宮、一張牌，都有白話說明，不需要懂術語。
- 「追問走向」：沿用同一個盤，複製追問用的指令。
- 紀錄可以補記 AI 的解讀重點和事後的實際結果，方便回頭驗證。
- 深色、淺色兩種主題，手機和電腦都能用。

## 在手機上使用

用手機瀏覽器打開網址，再加到主畫面：

- iPhone（Safari）：分享按鈕 → 加入主畫面
- Android（Chrome）：選單 → 加到主畫面

## 隱私

- 這是純靜態網頁，沒有伺服器，也沒有帳號。
- 網頁不會傳送任何資料出去，沒有分析或追蹤工具，不使用 cookie。
- 你的問題、盤面和筆記只存在自己瀏覽器的本機儲存空間，其他人讀不到，換一台裝置也不會跟著過去。
- 只有在你自己按下複製、貼到 AI 服務時，內容才會離開你的裝置。

## 排盤的正確性

- 四柱與節氣使用 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT 授權），以節氣交節的實際時刻為準，23:00 換日。
- 六爻與奇門的拆補法盤面，曾與其他排盤工具和開源程式逐項交叉比對。
- 奇門另以兩萬張隨機盤檢查內部一致性。
- 置閏法各家實作不一，本工具以《統宗》書中的範例驗證，結果可能與其他網站不同。
- 塔羅洗牌使用瀏覽器的密碼學亂數，經四十萬次洗牌檢驗，各張牌與正逆位的機率均勻。

## 聲明

僅供文化探索與自我整理參考。重要的決定請回到現實資訊，並諮詢相關專業人士。
