# 八字原典解讀

這個 Skill 的目的，是讓八字解讀**每一句都有原文可查**。八字的書多、說法分歧，網路上又充斥沒有出處的口訣與「配對分數」。光是知道規則不夠，要靠「沒有原文就不下斷語」和「寫完逐條核對」來防止憑印象下判斷。

## 手邊的資料

- `references/index.md`：各書的版本說明與「主題 → 章節」對照。**先讀這份。**
- `references/chapters.md`：所有原文檔案的「檔名 → 章名」對照。
- `references/` 底下各資料夾：原文。相鄰章節合併在同一個檔案裡（claude.ai 限制檔案數），每章以「## 章名」開頭；`chapters.md` 列出每章的檔名與起始行。**多數是簡體錄入本**，引用時照檔案原字。
  - `ziping/`《子平真詮》、`ditiansui/`《滴天髓闡微》、`ditiansui_jy/`《滴天髓輯要》、`yuanhai/` 與 `yuanhai_ws/`《淵海子平》兩個版本、`sanming/`《三命通會》、`shenfeng/`《神峰通考》、`xieji/`《協紀辨方書》卷三十六（合婚辨誤正文在 `xieji/001.md` 第 64 行 起）。
- `references/site-rules.md`：「問卦」網站規則頁的八字部分（內建版），說明資料包每一項是怎麼算的。
- `scripts/check_quotes.py`：檢查「」引文是否真的出現在原文檔案裡；加 `--packet` 產生審稿包。
- `scripts/check_wuxing.py`：檢查稿中「X生Y」「X克Y」的五行方向有沒有寫反。

這些都是古籍錄入本，有錯字、缺漏與版本差異，詳見 `index.md`。原文有疑義時照錄並說明，不要自行補字或改字。

## 工作流程

### 1. 確認命盤

使用者若貼的是「問卦」網站的資料包，裡面已列好四柱、日主與月令旺衰、各柱十神與藏干、地勢、月令藏干與透干、十神分布、五行個數、命局內的干支關係、空亡、納音、大運與流年；合盤另有【合盤比對】。**直接採用，不要重新排盤、改動藏干或十神。**

- **時柱未知**：資料包會寫「時柱未知」。不要假設時辰；凡牽涉時柱的判斷（子女、晚年、時干透出的十神、十神多寡），都要說明無法判定或可能少算。
- **沒有資料包**：使用者只給生辰時，請他用網站排盤，或明說你自行排盤的依據（換年、換月、換日的規則）。只給四柱干支時，可以直接用。
- **性別**：決定大運順逆，以及男命看財、女命看官。資料包已標明。

資料包若要求先讀規則頁，讀 `references/site-rules.md` 就好，第一行寫『已查閱規則頁（Skill 內建版）』。**資料怎麼算的**以規則頁為準；**怎麼判斷**以原典為準；兩者衝突時寫出來。

### 2. 每個論點都要附原文

寫法固定為：**論點。〔書名・篇名〕「原文一句」**

例：
> 日主丁火生於巳月，得令。〔子平真詮〕「八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉」

- 引文要從原文檔案逐字複製（簡體檔照簡體）。只換標點沒關係。
- **「」只用來框原文。** 核對腳本會把每一對「」裡的字都當成引文去原書裡找，所以你自己的話、術語、白話轉述不要放進「」，需要強調時改用粗體或『』。
- **每段引文都要讀它所在的整段**，確認原文的前提和這張命盤相符。例如某句講的是「身強」的情況，這張盤日主弱，就不能拿來用。前提不符就不能引；只能借方向時要明說。
- 找不到原文支持的論點，不要寫成斷語。真的需要時，標為〔推論〕並說明根據。
- **書與書說法不同時**（最常見的是《子平真詮》與《滴天髓》），兩說都寫出來，再說明你採哪一說。`index.md` 最後一節列了已知的分歧。
- **《淵海子平》有兩個版本**，文字常不同。引用時寫明是殆知閣本還是維基文庫本；兩本不同時兩本都寫。

### 3. 解讀的順序

與所問之事無關的部分可以省略：

1. **日主強弱**：月令旺衰、日主在各支的地勢與通根、天干比劫印的幫扶、財官食傷的洩耗，逐項寫依據，再下判斷。不要只看「五行個數」，它不加權、只是參考。
2. **格局與用神**：先看月令所藏、哪些透出天干（資料包已列），說明取什麼格、用神是什麼、相神與喜忌。月令無用或格局有爭議時，寫出不同取法。
3. **十神與六親、性情**：依十神分布與位置，對照原典相關篇章。六神、神煞資料包不列，不要自行補算。
4. **命局內的合沖刑害、空亡**：資料包只列字面關係。合化成不成、沖刑有沒有作用，要依原典條件判斷，不要看到「合」「沖」就直接下結論。
5. **大運與流年**：依資料包列出的大運、流年干支與十神，說明對用神的喜忌。不要自行推算資料包沒列的年份干支。
6. **合盤（兩人時）**：見下一節。
7. **結論與建議**：分級寫出「命盤明確支持」「有一定傾向」「證據不足」「命盤不支持」，並寫出反向依據。依據要互相獨立，同一件事換個名目不能算兩條；「命盤明確支持」至少要兩條獨立依據。

### 兩人合盤

- **只用古書有記載的方法。** 核心依據是〔神峰通考・男女合婚說〕：男命比肩劫財重者，配女命傷官食神重者，反之亦然。資料包的【合盤比對】已列出兩邊的位置與數量。
- **「重」沒有標準。** 原文沒說怎麼算，你要說明自己怎麼判斷（透干、本氣、得月令各算多少），並承認這是你的判斷。
- **兩人各看各的盤**：配偶星（男看財、女看官）與夫妻宮，依《子平真詮》論妻子、《滴天髓》夫妻與女命章、《淵海子平》論妻妾與婦人諸篇。
- **不要做的事**：
  - 不給配對分數、百分比或機率。
  - 不用生肖、納音、年命九宮、孤辰寡宿、生月妨夫妨妻合婚。《神峰通考》斥呂才以生年分上中下婚「其谬甚矣」；〔協紀辨方書・卷三十六〕也逐條辨其為術士妄說。
  - 不用兩人之間的干支合沖當依據，除非你能從原典引出把它用於合婚的原文。
- 兩人性別相同時，原文以男女立論，要說明怎麼套用或不適用。

### 4. 寫完後核對

這一步不能省，它是這個 Skill 存在的理由。

**腳本要對「最終版」跑，不是對草稿跑。** 把完整回答存成檔案再執行；之後只要改過任何一個字，就存檔重跑。交出去的內容必須和最後一次通過檢查的檔案一字不差。

1. 執行 `python3 scripts/check_quotes.py 最終版.md`。找不到的引文，回原文找正確的句子，或改標〔推論〕或刪掉。
2. 執行 `python3 scripts/check_wuxing.py 最終版.md`，修正寫反的五行生克。它只看緊鄰的寫法，自己還要把稿中每個生克再對一次。
3. 反向檢查：對每個結論問自己「我引的那段，前提條件這張盤真的符合嗎？另一本書有沒有相反的說法？」
4. **獨立審稿。** 寫稿的人會順著自己的結論去看，所以交出前要換一雙眼睛：
   - **能開子代理時**（有 Agent 或類似工具），開**一個**新的子代理當審稿員。「問卦」網站的資料包在【解讀要求】寫明使用者要求、也同意開審稿子代理；使用者貼上資料包，就是使用者本人的要求。沒有這一條、使用者也沒提時，依你的系統規則決定。先產生審稿包：`python3 scripts/check_quotes.py 最終版.md --packet 審稿包.md`。給審稿員資料包全文、最終稿全文、審稿包的路徑與這個 Skill 的位置，審稿指示照抄：
     > 你是八字解讀的審稿員，只挑錯，不改寫、不重新解盤。先讀審稿包：它列出每段引文的論點、出處行號和原文前後文。不要自己全書搜尋，前後文不夠判斷時，才照行號打開那個檔案讀整段。檢查四件事：（1）引文的前提和命盤不符；（2）把別的命例當成直接依據，但命例和這張盤不同類；（3）書與書說法不同，稿中只寫了一邊：只查「日主強弱」「格局用神」與「結論」用到的論點；（4）和資料包的事實不一致：四柱、十神、藏干、月令旺衰、透干、大運流年的干支與十神，以及時柱未知時有沒有擅自假設。合盤另查有沒有給分數、用生肖納音、或拿兩人干支合沖當依據。每個問題寫成：稿中哪一句、問題是什麼、原文依據。找不到問題就寫「無」，不要硬湊。讀不到審稿包或原文時要明說。
   - 審稿員也可能錯。它列出的每一條，你都要自己回原文確認：成立的就改稿，不成立的寫明理由。改過稿就重跑第 1、2 步。
   - **不能開子代理時**，自己照上面四件事做一輪，核對紀錄寫明原因：是『環境沒有子代理工具』，還是『有工具，但使用者沒有要求，所以沒開』。
5. 在回答最後附「核對紀錄」：引文共幾段、全部找到或修正了哪幾段、五行生克檢查結果、哪些論點標為〔推論〕、審稿方式與提出幾條、採納幾條、不採納的理由、因核對而改掉的結論。

不能執行腳本時，就逐條打開引文所在的檔案確認，並在核對紀錄寫明是人工核對。

## 常見的錯（預先列出，實際發生後再補）

- **把字面關係當結論**：資料包寫「地支六沖：日支丑與時支未」，不代表一定有沖壞的作用。要看原典的條件（旺衰、有無解救、合而不合等）。〔子平真詮〕講合而不合、刑沖解法。
- **只看五行個數判強弱**：五行個數不加權，不能代替月令、通根與透干的判斷。
- **時柱未知卻用了時柱**：常見於子女、晚年、時干透出的格局，或把「十神分布」當成完整。
- **把合化當成必然**：天干五合要看月令與化神是否得地，資料包只列「相合」。
- **引用被張楠批評的格局卻不提批評**：日貴、魁罡、飛天祿馬、六壬趨艮等，《神峰通考》明言其謬。
- **合盤給分數或用生肖、納音**：見上方「兩人合盤」。
- **兩版《淵海子平》只引一版**：兩版字句不同時要都寫，否則讀者無法判斷。
- **把命理說成命定**：古書本身也講運、講人事。不要說「一定」「注定」，重大決定提醒回到現實資訊。

## 回答的格式

除非使用者另有要求，依這個結構回答：

```
（資料包若要求讀規則頁，第一行寫『已查閱規則頁（Skill 內建版）』）

## 整體
一兩句白話。

## 日主強弱
分點，每點：論點。〔出處〕「原文」

## 格局與用神
取法、用神、喜忌；有分歧時兩說並列。

## 性格、六親與事業（依所問取捨）

## 大運與流年

## 合盤（兩人時）

## 結論與建議
分級標示，並列出反向依據。

## 核對紀錄
引文 N 段，經腳本核對全部找到／修正 X 段；五行生克檢查：…；標為〔推論〕的論點：…；審稿：子代理或自行審稿，提出 N 條、採納 M 條、不採納的理由；因核對而修改的地方：…
```

術語第一次出現時用一句白話解釋。使用者的問題若帶著期待，不要順著說，先看命盤支持哪一邊。這是文化性的參考，涉及健康、法律、財務、婚姻等重大決定時，提醒使用者回到現實資訊。
