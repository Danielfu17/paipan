# 六爻原典解讀

這個 Skill 的目的，是讓六爻解讀**每一句都有原文可查**。使用者曾經遇過這樣的問題：規則都寫在指令裡，解讀者還是憑印象寫出原典沒有、甚至相反的論斷（例如把靜爻的「合起」說成「合絆」，或說「用神生日辰是洩氣」）。光是知道規則不夠，要靠「沒有原文就不下斷語」和「寫完逐條核對」來防止。

## 手邊的資料

- `references/index.md`：兩部書的章節地圖，依主題與問事類別指到檔案。**先讀這份。**
- `references/digest.md`：先前逐章對照原文整理出的判準摘要（用神、原忌仇神、各種標記、應期二十一條、兩書差異），每條附出處。拿它當地圖，找到章節後仍要讀原文、引原文。
- `references/chapters.md`：所有原文檔案的「檔名 → 章名」對照。檔名只用數字。
- `references/zengshan/`：《增刪卜易》按章切開的原文（繁體）。
- `references/zhengzong/`：《卜筮正宗》按章切開的原文（**簡體**）。
- `references/site-rules.md`：使用者的排盤網站「問卦」規則頁的六爻部分（內建版，隨網站更新同步）。說明資料包裡每一項是怎麼算的，例如 23:00 換日、進神退神採哪八組、卦之反吟怎麼標、應期參考怎麼列。
- `scripts/check_quotes.py`：檢查你寫的「」引文是否真的出現在原文檔案裡。
- `scripts/check_wuxing.py`：檢查稿中「X生Y」「X克Y」的五行方向有沒有寫反。

兩部書都是清代典籍，有錄入錯漏與缺章，詳見 `index.md` 最後一節。原文有疑義時照錄並說明，不要自行補字。

## 工作流程

### 1. 確認盤面與問題

使用者若貼的是「問卦」網站的資料包，裡面已列好本卦、變卦、各爻、月建日辰、旬空、用神與原忌仇神、待判定的標記、應期參考和日柱換算表，直接採用，不要重新排盤或改動納甲。

資料包另有六項由程式依原文條目比對的事實，有列出就要逐項採用：
- **伏神能否出現**（用神是伏神時）：伏神的旺衰、日月飛神動爻對它的生克沖合，以及符合〈飛伏神章〉「伏神有用」六條、「終不得出」五條中的哪幾條。
- **原神、忌神的有力與無力**：符合〈元神忌神衰旺章〉哪幾條。
- **三合局**：成局方式、局的六親、世爻在不在局內、局對用神的生克。
- **用神、世爻的墓與絕**：入日墓、動墓、化墓時，列出月令旺衰、被誰克、墓神有沒有被沖破，並對照〈隨鬼入墓章〉的真墓條件；絕於日時列出生扶，土爻逢巳對照〈生旺墓絕章〉「論生不論絕」。
- **動爻對各爻的生克沖合**：每個動爻對其他各爻的關係；動爻沖克世爻、應爻時有「注意」一行，**一定要寫進解讀**。
- **逐日關係表**：未來 30 日每天的日辰對用神的生克，以及值、沖了哪一爻。

資料包的「各爻」只標字面關係，例如『墓於日』『絕於此日』『月破』。**字面標記不等於判定**：墓要看真不真，絕要看有沒有生扶，破要看到底不到底。資料包沒有替某個標記列出判準時，自己回原文查條件再判，不要照字面寫成入墓、逢絕。

這些只列事實，不下結論；兩邊條目都符合時，兩邊都要寫出再權衡。

開始之前確認兩件事，缺了就先問一句，或明說你採用的假設：
- **問的是什麼事**：決定用神取哪個六親。
- **替誰問、對方是誰**：自占與代占的用神不同；感情題要知道問的人是男是女（男占看妻財、女占看官鬼），不明確時以應爻為對方。

資料包若要求先讀規則頁，讀 `references/site-rules.md` 就好，不必上網；第一行寫『已查閱規則頁（Skill 內建版）』。兩種資料的分工：
- **資料怎麼算的**，以規則頁為準。例如資料包標了「化退神」，它依的是規則頁寫的那八組；標了「外卦反吟」，依的是規則頁寫的偵測方式。
- **怎麼判斷吉凶與應期**，以原典為準。
- 兩者衝突時（例如規則頁採《卜筮正宗》的八組進退神，《增刪卜易》只有七組），把衝突寫出來，說明你採哪一邊，不要默默挑一邊。

### 2. 每個論點都要附原文

寫法固定為：**論點。〔書名・章名〕「原文一句」**

例：
> 初爻寅木靜而與月建亥合，判為合起，有力。〔增刪・六合章第十九〕「爻靜或與日月動爻合者得合而起。卽使爻值休囚亦有旺相之意。」

- 引文要從原文檔案逐字複製（《卜筮正宗》保留簡體）。只換標點沒關係。
- **「」只用來框原文。** 核對腳本會把每一對「」裡的字都當成引文去原書裡找，所以你自己的話、術語、白話轉述不要放進「」，需要強調時改用粗體或『』。
- **每段引文都要讀它所在的整段和書中的卦例**，不是只確認那一句存在。寫下兩件事：原文的前提是什麼（例如『世應俱空』『旺相』『墓於日或日建沖克』），書中舉的例子是哪一種卦。前提不符就不能引；例子不涵蓋這張盤的情況（例如書中只舉坤巽互變，你的盤是巽變乾），要明說只能借方向。
- 找不到原文支持的論點，不要寫成斷語。真的需要時，標為〔推論〕並說明你根據什麼推。
- **下推論之前，先在兩部書裡找同類的卦例。** 用卦名（例如『小畜』『乾』）、卦變（例如『變干』『之乾』）、相同的爻變（例如『未化午』『未土化』）去搜 `references/zengshan/` 與 `references/zhengzong/`（《正宗》是簡體，乾寫作「干」）。找到了就以書中的斷法為準；找不到才標〔推論〕。
- 原文本身有分歧（兩書說法不同、或作者並列兩說），把兩說都寫出來，再說明你採哪一說。

### 3. 解讀的順序

依原典的思路，大致如下；與所問之事無關的部分可以省略：

1. **標記判定**：逐項判定資料包列出的「待判定的標記」，以及你看到的其他關鍵狀態（旬空真空與否、月破到底破與否、日沖是暗動或日破、合起或合絆、入墓、化進化退）。每項一行：判定結果＋出處引文。後面的分析必須與這裡一致。
2. **用神**：取哪一爻、為什麼；兩現時怎麼取捨（〈兩現章〉）；不上卦時怎麼處理（〈飛伏神章〉）。用神是伏神時，把資料包列出的「伏神有用」與「終不得出」符合的條目都寫出來，再判斷能不能出。
3. **旺衰**：用神、原神、忌神、仇神各自在月建、日辰下的狀態，以及動靜、生克。原神、忌神照資料包列出的有力、無力條目寫，兩邊都有時說明你怎麼權衡。
4. **世應與卦象**：世應關係、六合六沖、反吟伏吟、卦變。
5. **結論**：分級寫出「盤面明確支持」「有一定傾向」「證據不足」「盤面不支持」，並寫出反向的依據。依據要互相獨立：同一件事換個名目不能算兩條（例如兄爻發動與兄弟局）；前面已判定無力的忌神、不作真空的旬空，不能再當主要依據。「盤面明確支持」至少要兩條獨立依據，湊不到就降為「有一定傾向」。
6. **應期**：以 `digest.md` 的「應期」二十一條為清單（它整理自〈各門類應期總注章〉，並補上伏神、兩現、三合等來自其他章的條目；引原文時回到各條標明的章節去引），**逐條過一遍**，每條寫一行「適用／不適用：理由」，適用的再寫出地支，用資料包的日柱換算表換成日期。逐條過的原因是：只挑想到的幾條，最常漏掉的是「大象吉而受克，須待克神受克」這類看的不是用神本身、而是克用神那一爻的條目。沒有換算表時，不要自己推算干支，請使用者提供或只給地支。沒有可用依據就直說。
   點名任何一天（應期、轉折、要避開的日子）時，先查資料包的「逐日關係表」，寫出那天日辰對用神是生、扶、克、沖或值，再寫它沖動或填實了什麼。同一天正反力量都有時，寫成「變化集中」，不要只寫一面。
7. **建議**。

### 4. 寫完後核對

這一步不能省，它是這個 Skill 存在的理由。

**腳本要對「最終版」跑，不是對草稿跑。** 把要交給使用者的完整回答存成檔案再執行；之後只要改過任何一個字，就存檔重跑。交出去的內容必須和最後一次通過檢查的檔案一字不差，整理成最終版時也不得刪掉用神、原神、忌神的旺衰與生克依據。

1. 執行 `python3 scripts/check_quotes.py 最終版.md`。找不到的引文，回原文找正確的句子，或把那個論點改標〔推論〕或刪掉。
2. 執行 `python3 scripts/check_wuxing.py 最終版.md`，修正它列出的五行生克方向錯誤。它只看緊鄰的寫法，所以自己還要把稿中每個生克、每個旬空的說法再對一次。
3. 反向檢查：對每個結論問自己「我引的那章，有沒有說了相反的話？原文的前提條件，這張盤真的符合嗎？書中的例子和這張盤是同一類嗎？」特別是下面「常見的錯」那幾項。
   另外逐爻掃一遍：每個動爻對世爻、應爻、用神有沒有生克沖合，你都寫到了嗎？
4. 核對腳本只能證明引文存在，證明不了推理正確。推理錯誤只能靠第 2、3 步。
5. 在回答最後附一段「核對紀錄」：引文共幾段、全部找到或修正了哪幾段、五行生克檢查的結果、哪些論點標為〔推論〕、因核對而改掉的結論。

不能執行腳本時，就逐條打開引文所在的檔案確認，並在核對紀錄中寫明是人工核對。

## 常見的錯（都曾經實際發生過）

每一條都附原文，判斷時以原文為準：

- **合起與合絆**：靜爻逢合是合起、有力；動爻逢合才是合絆、受阻待沖。〔增刪・六合章第十九〕
- **爻不能傷日月**：不要因為「用神生日辰」就說用神洩氣。〔增刪・動變生克沖合章第十五〕「日月如天，能生克動爻、靜爻、變爻、飛爻、伏爻、而諸爻不能傷日月。」
- **變爻只管本位**：變爻只能生克沖合本位的動爻，不能生克他爻。〔同上〕
- **靜爻不是一律無作用**：安靜而旺相的爻，可以生克休囚的爻；休囚而安靜的爻才無力。不要憑印象說「靜爻不能生克」。〔增刪・動靜生克章第十四〕
- **月破的動爻仍能生克**，出月、實破之日、逢合之日則不破；靜而無生助才是到底破。〔增刪・月破章第二十七〕
- **旬空不一律作無用**：旺、動、得日月動爻生扶、化空、伏而旺相都不為空；臨月建者在旬內仍為空。〔增刪・旬空章第二十六、月將章第十六〕
- **反吟有輕重**：用神本身不變沖克，雖主反覆亦主事就；用神化沖克才凶。〔增刪・反伏章第二十五〕
- **應期別漏條**：用神有生扶而被克時，應在「克神受克」之日，這條容易漏。〔增刪・各門類應期總注章〕
- **六神只作輔助**，不單憑六神定吉凶，人物爻臨玄武、螣蛇不得直接說成欺騙或不忠。〔增刪・六神章第十八；正宗・六兽评论第七〕
- **五行生克的方向**：「金克木，木克土，土克水，水克火，火克金。」〔增刪・五行相克章第十二〕曾有解讀寫出「午日克亥水」，實際是水克火，接著又引〈月將章〉去化解一個不存在的克。每寫一個「X生Y」「X克Y」，都先把兩邊換成五行再對一次；`scripts/check_wuxing.py` 會自動抓緊鄰的寫法。
- **旬空、日破、月破只論起卦當時的卦中之爻，不論未來的日子**：旬空是起卦當日所在那一旬缺的兩個地支，〔增刪・旬空章第二十六〕「如甲子至癸酉日爲一旬，此十日之內，並無戌亥，以爻逢戌亥爲空亡」；日破是起卦當日的日辰沖卦中衰弱的靜爻，〔增刪・暗動章第二十二〕「靜爻休囚日辰沖之爲破」；月破是起卦當月的月建沖卦中之爻。這三個詞都在描述起卦那一刻的盤面。未來某一天沖到某爻，是應期上的「逢沖」，不能說那天「是旬空」或「造成日破」，也不能因此把那天的應期打折扣。這類錯誤已經出現過兩次。
- **真空有季節條件**：旬空之外，野鶴另列季節真空，旺衰再好也不能免。〔增刪・旬空章第二十六〕「眞空卽春土、夏金、秋木、三冬逢火是眞空」亥子丑月（冬）的火爻、寅卯辰月（春）的土爻、巳午未月（夏）的金爻、申酉戌月（秋）的木爻落旬空，都是真空。判定旬空時先查這一條，再看生扶。
- **「世空元動」「世衰元靜」的「元」是世爻的原神**，不是用神的原神。〔增刪・各門類應期總注章〕「世衰元靜，必然是元气逢沖。如秋占圖謀，得困卦後逢巳日成事」困卦世爻寅木，原神亥水，沖亥為巳日，所以應在巳日。先寫出世爻的五行，再找生它的那一爻。另外，暗動的爻算動，不能同時拿來套「元靜」。
- **三合局要有發動的爻在局中**：〔增刪・六合章第十九〕列出四種成局方式：「一卦之內有一爻動而合局者一也。若兩爻動一爻不動亦成合局者二也。」其餘兩種是內卦、外卦的初三爻或四六爻發動，與變出之爻成局。三個地支都在卦中，但發動的爻不在局裡，就不成局；只靠某個動爻化出的變爻去湊兩個靜爻，也不符這四種。不成局就直說不成局，不要列為「警示」。
- **伏神只寫不利的一面**：曾經只寫「用神伏藏又休囚」，漏了飛神戌土生伏神酉金（飛來生伏）、二爻辰土發動生伏神又沖飛神，這幾條都是〈飛伏神章〉的「伏神有用」。〔增刪・飛伏神章第二十八〕「伏神得飛神生者三也」先把有用、不得出兩邊的條目都列出來，再下判斷。
- **生扶用神的日子被寫成阻隔**：曾經把未、申、酉、戌四天寫成「有阻隔的四天」，只因為那幾天沖到退神、仇神；但這四天的日辰對用神酉金分別是生、扶、值、生。點名日子時，先寫日辰對用神的生克，再寫它沖了什麼。
- **同一個依據算兩次**：曾經把「兄爻發動」和「三合兄弟局」當成兩條獨立依據，又把前面判定無力的忌神拿來支持「盤面明確支持」。〔增刪・元神忌神衰旺章第十〕「此忌神者乃無力之忌神也，諸占化凶爲吉」判定無力後，結論要和判定一致。
- **入墓不等於真墓**：曾經看到資料包寫『墓於日』，就判用神入墓、寫成『今天她是收著的』，當成主要反向依據。〔增刪・隨鬼入墓章第三十〕「此三墓者﹐自占看世爻﹐旺相者非眞﹐代占看用神﹐用神旺相者非眞﹐惟世爻休囚被克﹐而又入墓者﹐是也。墓神破﹐日月動爻沖破﹐亦非眞也。」休囚但沒有被克的，不算真墓。
- **土爻逢巳不一定是絕**：曾經把『用神絕於此日』直接寫進日子的判斷。〔增刪・生旺墓絕章〕「土爻𨿽絕於巳，必須休囚無气，又逢巳爻謂之絕。若土爻旺相，或得日月動爻生扶，再遇巳爻，巳火反能生土，論生不論絕也。」
- **卦之反吟的引文範圍**：《增刪》〈反伏章〉舉的例子都是坤、巽互變；乾巽、坎離、艮坤、震兌的卦之反吟是《正宗》〈反吟卦定例第十一〉明列的。論輕重用《正宗》：〔正宗・十八問答第五問〕「凡得反吟卦，用神不变冲克者，事虽主反复，亦主事就，第嫌用神化冲克者，凡谋大凶．」曾經把《增刪》條文的『用神旺相』前提硬套在巽變乾上。
- **卦之回頭克不要先推論**：曾經憑推論說巽木變乾金是『忌神受克』，其實《正宗》就有幾乎同樣的卦例：〔正宗・十八問答第五問〕「小畜卦变干是卦之反吟也，所喜世与财爻长生于日，指此占以应爻作地头，临午火回头生合，比前利倍．」先找書中同類的卦例，再決定怎麼寫。
- **漏看動爻沖世**：曾經整篇沒寫到用神動來沖世爻。〔增刪・六沖章第二十〕「爻遇爻沖謂之相殺也。」資料包的「動爻對各爻的生克沖合」有列出時，每一條涉及世應、用神的都要處理。
- **把『世應俱空』的條文用在只有世空的盤**：〔增刪・婚姻章第八十二〕野鶴「倘得空而逢旺財鬼相生﹐先𨿽不允﹐後終還成」接在「世應俱空」之後，前提是世應都空。引用前先看上一句。
- **引文的前提要和盤面相符**：原文常帶條件，例如〈動靜生克章〉說的是「安靜**旺相**之爻」才能生克休囚之爻，盤上的爻若是休囚，這句反而說明它生克不動。引用前先確認原文的條件，這張盤是否真的符合。
