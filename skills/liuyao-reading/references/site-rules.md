# 「問卦」網站規則頁（六爻部分，內建版）

這是使用者的排盤網站 https://danielfu17.github.io/paipan/rules.html 中與六爻有關的段落，建置網站時自動同步到這裡。它說明資料包裡每一項資料**是怎麼算出來的**（網站的約定）；怎麼解讀，仍以原典為準。兩者衝突時，把衝突寫出來，不要自己挑一邊。

## 共通規則

- **曆法**：四柱與節氣由 lunar-javascript 計算。年柱以立春交節時刻換年，月柱以十二「節」的交節時刻換月（精確到分鐘），中氣不換月。

- **換日**：23:00 換日。23:00 之後的子時屬於次日的日柱。

- **時區**：使用者裝置的當地時間。資料包上的時間都是鐘錶時間，除非另外註明真太陽時。

- **真太陽時**（僅奇門可選）：鐘錶時間加上經度修正（每度 4 分鐘，相對於時區中央經線）再加上均時差。資料包會寫出修正的分鐘數。

- **資料的範圍**：資料包只包含盤面資料與字面上的生克、沖合關係。用神怎麼取、吉凶怎麼斷，由解讀者決定。

- **問句帶有預設結論**：問句含有已下定論的字眼（例如背叛、出軌、騙我、一定、為什麼他…）時，資料包在「所問之事」下方加一行「注意：問句帶有預設結論」。這只是依字面比對，不代表使用者的判斷錯誤；解讀者應先依盤面說明比較支持哪一邊，再回答問句。

### 月令旺衰（旺相休囚死）

以月建地支的五行為準：與月令同五行者旺，月令所生者相，生月令者休，克月令者囚，被月令所克者死。例如亥月（水）：水旺、木相、金休、土囚、火死。

## 六爻

- **起卦**：三枚銅錢擲六次，由初爻（最下）排到上爻。背面計 3、字面計 2，三枚相加：6 老陰（動，陰變陽）、7 少陽、8 少陰、9 老陽（動，陽變陰）。

- **數字起卦**：上卦數、下卦數各除以 8 取餘數，依先天八卦數（乾一、兌二、離三、震四、巽五、坎六、艮七、坤八，餘 0 作八）取卦；動爻數除以 6 取餘數（餘 0 作六）定動爻，未填時用上下兩數之和。

- **納甲**：京房納甲。

- **卦宮與世應**：八宮卦序，由八純卦依序變爻得出本宮、一世至五世、遊魂、歸魂。

- **六親**：以本卦所屬卦宮的五行為「我」。變爻與變卦各爻的六親，同樣以本卦卦宮五行為準。

- **六神**：依日干起，由初爻往上排：甲乙日起青龍、丙丁日起朱雀、戊日起勾陳、己日起螣蛇、庚辛日起白虎、壬癸日起玄武。

- **伏神**：本卦六爻缺少某個六親時，取本宮八純卦中該六親所在的爻，伏於本卦同一爻位之下；本卦那一爻稱為飛神。

### 依問題類別標出用神

起卦前可以選問題類別，以及是不是替別人問。資料包會標出用神以及原神、忌神、仇神各在哪一爻、是動是靜、有哪些標記。取法與應期原則逐章對照過《增刪卜易》與《卜筮正宗》原文。

| 用神 | 求財、失物看妻財；求官職、升遷看官鬼；考試錄取以官鬼為主，父母為文章並看；文書、證照、合約、長輩、房屋車輛看父母；子女、晚輩看子孫；兄弟、知交看兄弟；感情，男問看妻財、女問看官鬼，應爻只作輔助；自身健康、運勢、出行、官司看世爻（官司兼看應爻）。一般生意與手藝的收入看妻財。 |

| 代占 | 替別人問時，以那個人對應的六親為用神：父母長輩看父母，丈夫看官鬼，妻子看妻財，子女看子孫，兄弟姊妹與知交看兄弟；沒有親屬稱謂或交情淺的人看應爻。世爻仍代表來問的人。 |

| 原神、忌神、仇神 | 六親相生的次序是父母、兄弟、子孫、妻財、官鬼，循環相生，隔一位相克。生用神者為原神，克用神者為忌神，克原神而生忌神者為仇神。 |

| 用神不只一處 | 資料包會全部列出，次序是本卦、變爻、伏神。取旺捨衰、取動捨靜，其次取持世、臨月建或日辰者；論應期時取旬空、月破的那一爻。 |

| 用神不上卦 | 若月建或日辰的六親正是用神，可直接取用；否則看變爻化出的，再看伏神。資料包會列出月建與日辰各是什麼六親。 |

| 幾個要判斷的標記 | 旬空：旺相、發動或得生扶者不作真空，休囚安靜又受克者為真空。月破：臨日辰者不論破，動爻雖破仍能生克，靜而無生扶者為到底破。日沖：靜爻旺相為暗動，靜爻休囚為日破，動爻為沖散。月合、日合：靜爻為合起，動爻為合絆。這些由解讀者依旺衰判斷，資料包只標字面關係。 |

| 應期參考 | 追問時附上，依用神的狀態列出對應的地支：靜而逢值逢沖；動而逢合逢值；旬空待填實或沖空；月破待實破或逢合；逢合待沖開；入墓待沖開墓庫；化進神看本爻逢值逢合，化退神看變爻逢值逢沖；衰絕者遇生遇旺，太旺者逢墓逢沖；伏神待值日而出或飛神被沖。近事應在日時，遠事應在月年。 |

六沖卦、六合卦：內外卦三組對應爻位的地支全部相沖或全部相合。

## 應期換算表

奇門的資料包附上「定應期參考」，方法依《神奇之門》，程式只計算書中規則明確的兩項：

- **值符法**：值符旬首的地支，與值符所落之宮的地支相沖或相刑時，應期取旬首地支的六合支。

- **旬空法**：值符落在時旬空亡之支所在的宮時，應在該支被填實或出旬之後。

其餘方法（用神旺衰、空亡填實、沖墓、馬星、值使與時干的宮數等）書中只有一句、沒有細則，資料包只列為輔助，並要求解讀者不要自行補充細則。

六爻與奇門的資料包（包含一般解讀與追問）都會附上應期參考，以及由程式算好的換算表：未來 30 日的日柱、起局當日的十二時辰干支、下一次換月建的時刻。日柱以 23:00 換日，表上每個日期的日柱自前一晚 23:00 起算。把地支換算成日期時請查表，不要自行推算。
