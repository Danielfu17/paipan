# 原文索引

兩部書都已按章切成獨立檔案，檔名只用數字。先用下面的「主題對照」找到該讀的章，再打開檔案讀原文；完整的「檔案 → 章名」清單見 `chapters.md`。

- `zengshan/`：《增刪卜易》（清・野鶴老人著，李文輝增刪），繁體。
- `zhengzong/`：《卜筮正宗》（清・王洪緒輯），**簡體**錄入本。引用時照檔案原字，不要自行改成繁體，否則核對腳本會找不到。

找不到章節時，直接用關鍵字搜尋，例如 `grep -rn "暗動" references/`。

## 原文的限制

- 《增刪卜易》來自維基文庫，頁面標示校對度 25%～50%，錄入者也說「並未仔細校對，錯漏應該不少」。卷一部分章節比印刷本短（例如〈八卦章〉〈世應章〉只有幾行），缺第三十三、三十四、一百零二、一百零六、一百十二章。
- 《卜筮正宗》來自網路錄入本，為簡體字。十八論中的〈旺相休囚論第十三〉〈合中帶克論第十四〉〈合處逢沖沖中逢合論第十五〉〈伏吟卦定例第十二〉正文缺漏；相關議題請改查十八問答（第六、第十一、第十三問）。部分論說沒有獨立標題，混在前一個檔案裡（例如〈世應論用神第二〉在 `003` 檔內）。
- 原文有錯字或缺字時，引用照錄，並註明「錄入本如此」。
- 核對時讀過的版本與網址，見 `sources-read.md`。
