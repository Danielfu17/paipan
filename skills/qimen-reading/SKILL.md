# 奇門遁甲解讀

這個 Skill 的目的，是讓奇門解讀的**每一個事實都對得上盤面、每一個判斷都說得出依據**。使用者曾經遇過這些問題：把景門當成吉門；沒看出全盤伏吟，把伏吟必然出現的十干克應（天網四張、地網高張）當成針對這件事的訊號；日干和女方同為乙卻沒有說明怎麼區分；只列凶象，漏掉同宮的值符等吉象。這些都不是不懂規則，而是沒有逐項對、沒有核對。

## 手邊的資料

- `references/index.md`：所有參考資料的說明與「依問題找資料」對照表。**先讀這份。**
- `references/site-rules.md`：使用者的排盤網站「問卦」規則頁的奇門部分（內建版）。資料包每一項怎麼算的，以它為準。
- 公開版不含《神奇之門》讀書筆記（見 `references/index.md`）。下文提到 `judging.md`、`topics.md` 等筆記時，若手邊沒有，就以資料包與 `site-rules.md` 為準，並把依據寫成〔規則頁〕或〔推論〕。
- `scripts/check_qimen.py`：拿資料包核對稿中的吉凶分類與落宮有沒有寫錯。
- `scripts/check_wuxing.py`：檢查「X生Y」「X克Y」的五行方向。

## 工作流程

### 1. 先讀資料包，確認三件事

使用者貼的是「問卦」網站的資料包時，盤面已經排好，直接採用，不要重新排盤。資料包要求先讀規則頁時，讀 `references/site-rules.md`，第一行寫『已查閱規則頁（Skill 內建版）』。

讀完資料包，先確認：
- **所問之事與類別**：資料包有列「這類問題的用神」就以它為主；沒有的話依 `topics.md` 選，並說明理由。
- **誰代表誰**：資料包若有「注意：…同為…」的重疊提示（例如日干與女方同為乙），先寫一段說明你讓哪個天干代表誰、為什麼。無法區分就直說。重疊的兩個身分落在同一宮，就是同一宮的盤面，只看一次、不要當成兩個人各算一次；你選定的那個身分為主，另一個身分在結論裡註明「與某某同宮，無法分開」。
- **盤的整體結構**：有沒有全盤伏吟或全盤反吟，有沒有天顯時格等影響全局的格局。全盤伏吟時，每宮的十干克應都是伏吟必然產生的組合，分量要打折。

### 2. 逐宮列出用神宮的內容

每個用神所在的宮，把**門、星、神、天地盤干、空亡擊刑入墓**全部列出，每一項寫出吉凶（照資料包的標示）與旺衰，吉的和凶的都要寫。漏寫吉象和漏寫凶象一樣會讓結論偏掉。一宮有兩顆星（例如天芮與寄宮的天禽）就兩顆都寫。

**最終版不得刪減這一節。** 為了精簡而改寫時，可以縮短說明文字，但每個用神宮的門、星、神一項都不能少；核對腳本會檢查。

寫法：
> 巽四宮（庚，代表你）：值符（吉神）、天輔（吉星，星旺衰：廢）、杜門（中平，門宮比和）、庚加庚 太白同宮（凶，但全盤伏吟，分量打折）、值符伏吟。

### 3. 判斷的順序

依《神奇之門》的思路（見 `judging.md` 第六節）：

1. **橫看**：用神宮與宮之間的五行生克，這是判斷雙方關係與成敗的主軸。
2. **豎看**：一宮之內，星與宮、門與宮（迫、制、和、義）、天盤干加地盤干。
3. **旺衰**：月令旺衰看宮、門、干；九星用資料包的「星旺衰」。吉門要旺相才算真吉，凶門休囚則凶力減。
4. **主客**：先說誰是主、誰是客，再看時干陰陽與同宮的星宮關係對誰有利。
5. **遠近快慢**：內盤近而快，外盤遠而慢；陰遁時內外對調。伏吟主遲，反吟主速。
6. **權衡**：門最重，星與三奇次之，八神再次；先看凶格，再論吉格。重要結論至少要有兩項依據互相支持，並寫出反向的依據。
7. **結論分級**：盤面明確支持、有一定傾向、證據不足、盤面不支持。
8. **應期**：只用資料包「定應期參考」列出的方法，換算日期查「應期換算表」。兩種主要方法都不成立時，直說此盤沒有可用的應期依據，不要硬給日期。
9. **建議**。

每個判斷寫出依據，引筆記時寫〔神奇之門 p.N〕或〔規則頁〕。沒有依據的推論標〔推論〕。

### 4. 寫完後核對

**腳本要對「最終版」跑，不是對草稿跑。** 先把要交給使用者的完整回答（包含先說明、逐項、判斷、結論、建議）存成檔案，資料包也存成檔案，再執行下面的腳本。之後只要改過任何一個字，就存檔重跑一次；交出去的內容必須和最後一次通過檢查的檔案一字不差。

1. 執行 `python3 scripts/check_qimen.py 資料包.md 最終版.md`。修正它列出的吉凶分類、落宮錯誤，以及「用神宮沒有寫全」（某宮的門、星、神沒出現在稿中）。
2. 執行 `python3 scripts/check_wuxing.py 最終版.md`，修正五行方向的錯誤。
3. 反向檢查：每個用神宮，吉象和凶象都寫了嗎？引用的格局或十干克應，是不是伏吟、寄宮造成的結構性組合？凶神凶門有沒有被寫成已經發生的事實？
4. 腳本只抓得到常見寫法，沒列出的不代表都對；它也證明不了推理正確。
5. 在回答最後附「核對紀錄」：兩支腳本的結果、修正了哪些地方、哪些論點標為〔推論〕。

不能執行腳本時，逐項回資料包對照，並在核對紀錄寫明是人工核對。

## 常見的錯（都曾經實際發生過）

- **門的吉凶查錯**：開門、生門大吉，休門吉，杜門、景門中平，死門、驚門、傷門凶〔神奇之門 p.100–101〕。景門不是吉門。資料包每宮已經標了吉凶，照抄就不會錯。
- **全盤伏吟的十干克應當成訊號**：六甲時全盤伏吟，每宮必然是「某干加同一干」，坤二宮另有中五寄來之干。這些名稱（天網四張、地網高張等）不是針對所問之事出現的，分量要打折。伏吟本身主停滯、維持現狀；逢天顯時格則伏吟不作凶論。
- **用神重疊沒處理**：感情題以乙為女方、庚為男方，但日干、時干也可能剛好是乙或庚。先說明怎麼區分，再往下解讀。
- **只列一邊的象**：同一宮的值符、吉星、旺相的凶星，都會改變判斷，要全部列出再權衡。
- **草稿寫全、最終版刪掉**：曾經草稿通過核對，整理成最終版時卻刪掉了天禽、九天、天英。腳本只對它讀到的那個檔案負責，所以要對最終版跑。
- **把伏吟必然的組合當成扣分理由**：例如三奇受刑若是換一局就不會出現的組合，才算這張盤自己的訊號；伏吟造成的才打折。判斷是不是結構性組合時，說明理由。
- **把凶神凶格當成事實**：人物宮出現玄武、螣蛇、白虎、驚門、凶格，只能當傾向，不得寫成隱瞞、欺騙、不忠或已經發生。
- **把凶象套到別人身上**：落在你年命宮的凶象，描述的是你的處境，不能拿來指對方。
- **星的旺衰用錯方法**：九星的旺衰另有算法（星所生的月份最旺），不同於五行的旺相休囚死〔神奇之門 p.106–107〕。用資料包給的「星旺衰」。
- **內外盤方向**：陽遁坎一、艮八、震三、巽四為內盤；陰遁相反。
- **五行方向寫反**：金克木，木克土，土克水，水克火，火克金。每寫一個生克先換成五行再對一次。

## 回答的格式

```
（資料包若要求讀規則頁，第一行寫『已查閱規則頁（Skill 內建版）』）

## 先說明
所問類別、用神取法；有重疊時誰代表誰；盤的整體結構（伏吟、反吟、天顯時等）。

## 整體態勢
一兩句白話。

## 用神宮逐項
每個用神宮：門、星、神、干、標記，各寫吉凶與旺衰。

## 判斷
橫看、豎看、旺衰、主客、遠近，每點附依據。

## 結論
分級標示，並列出反向依據。

## 應期
依資料包的定應期參考；沒有依據就直說。

## 建議

## 核對紀錄
check_qimen：…；check_wuxing：…；修正：…；〔推論〕：…
```

術語第一次出現時用一句白話解釋。問題若帶著期待或懷疑（例如「她是不是背叛我」），不要順著說，先看盤面支持哪一邊。這是文化性的參考，重大決定請回到現實資訊與實際溝通。
