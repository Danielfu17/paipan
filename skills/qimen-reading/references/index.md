# 參考資料索引（公開版）

公開版只收錄「問卦」網站規則頁的奇門部分。作者自用版另有張志春《神奇之門》的讀書筆記（判斷總則、各類占問的用神、象意、格局、十干克應、應期），因為那本書仍受著作權保護，沒有公開。

| 檔案 | 內容 |
|---|---|
| `site-rules.md` | 資料包每一項怎麼算、各標記的定義、格局怎麼偵測、十干克應的版本、應期換算表 |

## 依問題找資料

| 要判斷的事 | 先看 |
|---|---|
| 這類問題的用神是誰 | 資料包的「這類問題的用神」 |
| 某宮的門、星、神好不好 | 資料包每宮已標吉凶 |
| 旺衰 | 資料包的五行生克速查與星旺衰 |
| 某個格局、某組十干克應 | 資料包的格局清單與十干克應 |
| 什麼時候應 | 資料包的定應期參考 → `site-rules.md` 應期一節 |

若你有自己的筆記，可以放進 `references/`，並在這份索引加一行說明。
